# Accessibility User Guide

## Offline Local Retrieval System

Version: Week 5 Prototype

Platform: Flutter Windows Desktop

Prepared by: Xuefei Yao

Date: 2026-08-03

## 1. Introduction

This guide explains the accessibility features provided in the Offline Local Retrieval System.

The application follows accessible interface design principles to improve usability for different users. Current accessibility features include:

- Keyboard-only navigation
- High Contrast Mode
- Dynamic Font Scaling
- Semantic labels for screen readers

## 2. Keyboard Navigation

The application supports keyboard-only operation.

Available keyboard controls:

- Tab – Move to the next control.
- Shift + Tab – Move to the previous control.
- Enter – Activate the selected control.
- Space – Activate buttons and switches.

## 3. High Contrast Mode

High Contrast Mode increases the visual contrast between foreground and background elements to improve readability.

To enable High Contrast Mode:

1. Open the **Settings** page.
2. Turn on the **High Contrast Mode** switch.
3. The application theme will update immediately.

Users can disable the option at any time using the same switch.

## 4. Font Size Adjustment

The application provides four predefined font size levels:

- Small
- Medium
- Large
- Extra Large

To change the font size:

1. Open the **Settings** page.
2. Move the **Font Size** slider.
3. The user interface updates immediately without restarting the application.

## 5. Screen Reader Support

The application includes semantic labels for important interface elements.

Screen readers can identify:

- Navigation buttons
- Search controls
- Accessibility settings
- Main application sections

These semantic labels improve compatibility with assistive technologies.
